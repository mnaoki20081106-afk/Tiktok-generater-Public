# 公開ページの作成モード再現

## 参照と範囲

ユーザー添付の `リンク埋め込み(1).txt` は link-card.online の作成画面のHTMLです。公開ページ自体は含まず、`assets/js/templates-ui.js?v=20260913a` が公開プレビューAPIを呼び出す構造でした。

2026-09-16に通常の公開プレビュー `https://link-card.online/api/tpl-preview.php` から7モードのHTMLを取得し、そのDOM構造・CSS・SVGを `lib/template-layouts.ts` に反映しました。認証やPRO機能の制限の回避は行っていません。既存のTikTok風は対象外です。

| モード | 参照側の識別子 | 再現する画面 |
| --- | --- | --- |
| ニュース風 | news | 白い記事画面、Y!ヘッダー、動画枠、媒体・本文・記事CTA |
| インスタ風 | insta | 縦長のストーリーズ誘導画面、進捗バー、中央アイコンと見出し |
| インスタライブ風 | instalive | 全画面背景、LIVE表示、参加リクエスト、流れるコメント |
| ライブ配信風 | live | 配信者・フォロー・視聴者表示、コメントとリアクション |
| X風 | x | 黒い投稿画面、ユーザー情報、メディア、反応数 |
| YouTube風 | youtube | 暗い再生画面、動画情報、コメント、関連動画、下部ナビ |
| ファイル共有風 | gofile | 暗いフォルダ画面、ファイル一覧、選択数、ZIPボタン |

## 実装

- `renderAlternateViewerHtml` を公開ページ・編集画面のiframeで共有。
- `content_data.templateSettings` にモード別の編集値を保存。ブラウザの下書きにも保存し、モード切替で保持。DBマイグレーションは不要。
- メディアは自サイトの既存アップロードを利用し、追加モードではTikTok用の背景トリミングを適用しない。
- 関連動画・ファイル行の見出し、サムネイルURL、個別URLを編集可能。直接再生できる動画URL、再生マーク、ループ、全画面タップを設定可能。
- 参照サービスの計測スクリプト・プレビュー専用のリンク無効化CSSは公開HTMLに含めない。公開時は既存の `/api/visit` を利用し、プレビューは訪問を記録しない。
- URLのスキームを制限し、ユーザー文字列をエスケープ。プレビューはsandbox内で表示し、外部遷移を無効化。
- 見た目用コメント・反応数は実績データではない。参照サイトのログイン、登録、ダウンロードそのものを提供する機能ではなく、指定URLへのリンクページ。

## 検証

`scripts/fixtures/link-card-layouts.json` は実際に取得した参照HTMLから生成したCSSのSHA-256とDOMタグ・クラスの並びです。テストはアプリのテンプレートを期待値にせず、この参照スナップショットと照合します。

`npm test` は7モードのCSS・DOM構造、可変行・コメント、招待URL、プレビュー計測の無効化、HTML/URLエスケープを確認します。CSS・DOM一致は、実ブラウザでのピクセル一致やTikTok招待成立の証明ではありません。

参照サイトの入力機能すべてを移植したものではありません。背景の膜、動画ファイルの直接アップロード、反応数の自動ランダム生成などは今回の表示再現の範囲外です。
